ПРОМПТ: КАРТОЧКИ ДЛЯ ЗАПОМИНАНИЯ ПО ОБЗР
================================================================
Для чего: получить набор карточек «вопрос — ответ» по теме урока, который можно распечатать или загрузить в приложение для карточек
Подходит для: Claude, GigaChat, YandexGPT и других ИИ-ассистентов.

КАК ПОЛЬЗОВАТЬСЯ
1. Скопируйте блок «ПРОМПТ» целиком.
2. Замените всё, что в [квадратных скобках], на свои данные.
3. Вставьте в ИИ-ассистент и отправьте.
4. Проверьте результат по списку «Что проверить» и доработайте под свою семью.
================================================================
ПРОМПТ
================================================================
Ты — помощник для подготовки карточек. Составь набор карточек для запоминания по школьному курсу ОБЗР.

Данные (замените на свои):
- курс: [НВП или БЖ], класс: [8–11];
- тема: [название темы];
- материал: [вставьте абзац из учебника или конспекта];
- число карточек: [15];
- для кого: [ребёнок, который готовится к контрольной].

Сделай карточки по правилам:
1. Одна мысль — одна карточка. Вопрос — не длиннее 12 слов, ответ — не длиннее 25.
2. Используй только факты из материала, который я вставил; не придумывай числа и даты.
3. Формат вывода: «вопрос; ответ» — каждая карточка на новой строке, без нумерации и пустых строк, чтобы файл можно было вставить в приложение для карточек.
4. После набора отдельным списком дай три карточки повышенной сложности («объясни, почему…»).
5. В конце напиши, какие карточки лучше повторять через день, а какие — через неделю.
Если не уверен в факте, пометь его словами «проверить по учебнику».
================================================================
ЧТО ПРОВЕРИТЬ
- Каждая карточка проверена по учебнику или конспекту урока.
- Нет карточек с одинаковым ответом на разные вопросы.
- Числа, сроки и последовательность действий совпадают с материалами на сайте.
- Ребёнок повторяет карточки вслух, а не только читает.
================================================================
Материал подготовлен с использованием инструментов искусственного интеллекта и проверен преподавателем. Носит методический и рекомендательный характер.
