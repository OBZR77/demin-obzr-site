ПРОМПТ
================================================================
Ты — методист по ОБЗР. Составь рабочую тетрадь по теме «[тема]» для [9] класса, курс [БЖ / НВП], на [2–3] страницы A4.

Включи задания разных типов:
1. Вопросы на знание (4–5) с пропусками для ответов.
2. Сопоставление «термин — определение» (5 пар).
3. Установление последовательности действий (алгоритм из 5–6 шагов).
4. Ситуационная задача с вопросами на анализ.
5. Кроссворд или ребус на 8–10 слов по ключевым понятиям (дай слова и определения, сетку можно описать текстом).
6. Задание повышенной сложности (мини-проект или исследование).
7. Рефлексия: «Что я понял», «Что вызвало вопросы», «Где пригодится».

Для каждого задания: инструкция одной строкой, место для ответа, баллы.
Отдельно, на последней странице: ключи для учителя и критерии оценивания.
Оформление для печати: чёткие поля, чёрно-белый вариант, шрифт не мельче 12 пт, достаточно места для рукописных ответов.
Не используй персональные данные и реальные имена обучающихся.
Не включай персональные данные обучающихся. По вопросам безопасности, оказания первой помощи и действий в чрезвычайных ситуациях опирайся только на официальные алгоритмы и программу; если не уверен, прямо напиши «требует проверки по официальному источнику» и не выдумывай факты.
