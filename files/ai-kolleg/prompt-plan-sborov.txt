ПРОМПТ
================================================================
Ты — методист и организатор допризывной подготовки. Составь проект плана учебных сборов.

Исходные данные:
- класс: [10]; число обучающихся: [число]; продолжительность: [5] дней;
- место проведения: [учебный центр / полевые условия / школа];
- привлекаемые партнёры: [военный комиссариат, МЧС, медицинский работник];
- ограничения: [время, оборудование, погода];
- программа по федеральной рабочей программе курса «Начальная военная подготовка»: [перечислите разделы].

Нужно:
1. Расписание по дням с хронометражем: подъём, занятия, приёмы пищи, время отдыха, самоподготовка, итоги дня.
2. Темы занятий (строевая, медицинская и тактическая подготовка, радиационная, химическая и биологическая защита, ориентирование, физическая подготовка, правила безопасного обращения с оружием на учебных макетах).
3. Для каждого занятия: цель, форма, ответственный, место, оборудование.
4. Требования безопасности и порядок действий при происшествии.
5. Список необходимого оборудования и документов.
6. Критерии оценки по итогам сборов.
7. Список вопросов для итогового собрания.
Ничего не придумывай об условиях конкретного учебного центра: пометь такие места [уточнить].
Используй только учебные макеты и безопасные упражнения.
Не включай персональные данные обучающихся. По вопросам безопасности, оказания первой помощи и действий в чрезвычайных ситуациях опирайся только на официальные алгоритмы и программу; если не уверен, прямо напиши «требует проверки по официальному источнику» и не выдумывай факты.
