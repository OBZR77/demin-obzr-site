ПРОМПТЫ: ИДЕИ ДОМАШНИХ ЗАДАНИЙ
================================================================
Для чего: получить варианты заданий разных типов и уровней
Подходит для: Claude, GigaChat, YandexGPT и других ИИ-ассистентов.

КАК ПОЛЬЗОВАТЬСЯ
1. Скопируйте блок «ПРОМПТ» целиком.
2. Замените всё, что в [квадратных скобках], на свои данные.
3. Вставьте в ИИ-ассистент и отправьте.
4. Проверьте результат по списку «Что проверить» и доработайте под свой класс.
================================================================
ПРОМПТ
================================================================
Базовый промпт
Ты — методист по ОБЗР. Предложи [6] вариантов домашнего задания по теме «[тема]» для [9] класса, курс [БЖ]. Время выполнения: не более [20] минут.
Раздели задания на два уровня: основное (обязательное, для всех) и повышенное (по желанию).
Типы: проектное, исследовательское, творческое, практическое (дома, безопасное), с использованием сайта.
Для каждого задания: формулировка для ученика (2–3 предложения), ожидаемый результат, критерии проверки (3 пункта), время.
Задания безопасны, не требуют опасных действий, не требуют сбора персональных данных других людей, выполнимы без специального оборудования.

Варианты запросов
1. «Сделай задание в виде ситуационной задачи: описание ситуации, три вопроса, образец ответа.»
2. «Предложи мини-исследование: составить схему безопасного маршрута от дома до школы и описать три риска.»
3. «Придумай творческое задание: памятка для младших школьников на тему урока, не более 8 предложений.»
4. «Сформулируй задание с использованием ИИ: ученик проверяет ответ ИИ по учебнику и находит одну ошибку или неточность.»
5. «Составь вопросы для семейной беседы по теме урока (5 вопросов), чтобы ребёнок рассказал родителям, что узнал.»
Не включай персональные данные обучающихся. По вопросам безопасности, оказания первой помощи и действий в чрезвычайных ситуациях опирайся только на официальные алгоритмы и программу; если не уверен, прямо напиши «требует проверки по официальному источнику» и не выдумывай факты.
